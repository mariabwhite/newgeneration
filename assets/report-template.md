# Эталон Monthly Report

Этот файл — единый канон для всех ежемесячных отчётов NG English.
Когда Claude генерирует новый отчёт — используется СТРОГО этот шаблон.

## Два типа отчётов

Внутри одной Notion DB живут оба типа, отличаются полем `Type`:

| Тип | Адресат | Когда применяется | Регистр |
|---|---|---|---|
| **parent report** | Родитель ребёнка | Ученик — несовершеннолетний (Иван, Дана, Соня, Аня Исаева, Изотова, Маракина, Федя, Сова Катя) | 3-е лицо: «Юля идёт вперёд», «Дане стоит закрепить» |
| **student report** | Взрослый ученик сам | Ученик — взрослый (Круглов, Лушина, Денис, Кузнецова, Сова Елена и т.п.) | Комбинированный: «Мы» для прогресса/календаря, «Вы» для задач — см. секцию ниже |

Структура тела (календарь → прогресс → зоны роста → задача → абонемент → короткое сообщение) — общая. Отличается только обращение и местоимения.

## Notion-поля (служебка, идут в properties страницы)

| Поле | Тип | Значение / пример |
|---|---|---|
| **Report** (title) | title | `2026-05 — Даниэлла Либова — parent report` |
| **Month** | text | `2026-05` (формат YYYY-MM) |
| **Type** | select | `parent report` (ребёнок) или `student report` (взрослый) |
| **Report Status** | select | `ready to send` (по умолчанию) → переключается на `sent` когда Маша отправила маме. **Только `sent` отчёты видны в кабинете родителя.** |
| **Recipient** | text | ФИО получателя, как Мария обращается. Пример: `Либова Юлия Игоревна` |
| **Student** | relation | связь с карточкой ученика в Students DB |
| **Short message** | text | 1–2 предложения для копи-паста в мессенджер. Дублируется из секции «Короткое сообщение». |
| **Source DOCX** | text | если отчёт импортирован из docx — путь к исходнику. Если сгенерирован Claude — оставить пустым. |

## Тело отчёта (контент страницы, Markdown)

Структура фиксированная. Каждая секция обязательна, если в правилах ниже не указано «опционально».
Ниже показан вариант для **parent report** — для **student report** меняются только обращения и местоимения (см. отдельную секцию «Тон student report» ниже).

```markdown
Добрый день!

Отправляю краткий отчёт по занятиям {{Имя ученика}} за {{месяц прописью}}.

# Календарь занятий — {{месяц}} ({{N}} занятий)

- **{{дата}}** — {{тема урока}}
- **{{дата}}** — {{тема урока}}
- ...

{{Если есть пропуски/переносы:}}
- **{{дата}}** — *перенос / пропуск / отмена* — {{короткое пояснение}}

**Все занятия проведены.** {{← если все completed; иначе: «Из {{N}} занятий проведено {{X}}, перенесено {{Y}}»}}

# По прогрессу

{{2–4 предложения от Марии о том, что наблюдается. Тёплый, профессиональный тон. Конкретика: что укрепилось, какой формат работает, что заметно.}}

# Зоны роста

{{Списком — 3–6 пунктов. Конкретные грамматические/лексические/навыковые блоки, которые нужно закрепить.}}

- {{зона 1}}
- {{зона 2}}
- {{зона 3}}

# Следующая задача

{{1–2 предложения о главном фокусе на следующий месяц. Что выводим в речь, что добиваем до автоматизма, какая методическая линия ведущая.}}

# {{Следующий-месяц}}-ский абонемент — {{N}} занятий

- Стоимость одного занятия: {{цена}} ₽

{{1–2 предложения. Дублируется в Notion-поле «Short message» — для копи-паста в мессенджер маме.}}
```

## Правила тона — общие

- **Обращение** — «Добрый день!» (нейтрально, не «Здравствуйте» — слишком сухо).
- **Подпись не нужна** — отчёт уходит из личного контакта Марии, и так понятно.
- **Не использовать слэнг / разговорщину**: «ребята», «зашло», «классно прокачала». Маша держит профессиональный регистр, без скатывания.
- **Грамматическое название тем — на русском, термин на английском в скобках при необходимости**. Пример: «прошедшее простое время (Past Simple)», но если адресат школьный — просто «Past Simple».
- **Нет «вилок» и неуверенности**. Не «думаю, что», «возможно». Только наблюдение: «грамматика подросла», «появилась устойчивость в speaking».

## Тон parent report (адресат — родитель ребёнка)

- **3-е лицо про ученика**: «Юля стабильно идёт вперёд», «Дане стоит закрепить word formation», «у Феди улучшилась интонация».
- **«Ученик/Юля/Дана»** — называть по имени, как Маша его называет. У одного ребёнка может быть «домашнее» имя (Даниэлла → Дана) — следить за карточкой ученика в Students DB.
- Открытие: `Отправляю краткий отчёт по занятиям {{Имя ученика}} за {{месяц}}.`

## Тон student report (адресат — взрослый ученик)

- **Прогресс и календарь — в «Мы»**: «Мы прошли», «Мы укрепили listening», «Наши занятия в апреле сфокусировались на…». Это создаёт тон совместной работы.
- **Зоны роста и задачи — в «Вы»**: «Вам стоит уделить внимание spelling», «Ваша ближайшая задача — вывести грамматику в свободную речь».
- **Имени ученика в теле обычно нет** — он адресат, обращение прямое.
- Открытие: `Отправляю краткий отчёт по нашим занятиям за {{месяц}}.`
- В разделе абонемента можно сохранить «Вы»: «Вам предстоит N занятий по {{дням}}» / «К оплате: …».

## Чего НЕТ в эталоне (и не должно появляться)

- ❌ «Паспорт формы» в теле (это устаревшая служебка из docx-импорта — теперь живёт в Notion-полях)
- ❌ «Источник DOCX» — служебка
- ❌ Эмоджи в заголовках секций (`# 📚 Что проходили` — не надо)
- ❌ Подпись «С уважением, Мария» — не нужна
- ❌ Звёздочки в заголовках секций (`# **Календарь**` — нет, только текст)
- ❌ Двоеточия в конце заголовков (`# Календарь:` — нет)
- ❌ Длинные секции «Что закрепляем дальше» + «Зоны роста» + «Следующая задача» — это дубль. Объединить в **Зоны роста** + **Следующая задача**.

## Опциональные секции (включать только если применимо)

- **Особенности / контекст** — если ученик долго болел / был в отпуске / поменял уровень. После «По прогрессу», перед «Зонами роста».
- **Диагностика** — если в этом месяце была диагностика (например, для TOEFL/IELTS студентов). Отдельной секцией перед «Зонами роста».
- **Платформа / материалы** — если использовали ProgressMe / Lingoda / собственные тренажёры NG, и это важно для родителя.

## Чеклист при генерации нового отчёта

1. **Определить тип**: parent report (если ученик — ребёнок) или student report (если взрослый). По карточке ученика в Students DB.
2. Прочитать Lesson Log за месяц — все entries по ученику.
3. Достать из карточки ученика: имя получателя (для parent), цена занятия, дни недели, цель.
4. Заполнить Notion-поля (служебка) — включая `Type`.
5. Сгенерировать тело по эталону, **применяя правильный тон** (parent → 3 л., student → Мы/Вы). Календарь — строго по датам Lesson Log.
6. Прогресс/зоны роста/задача — собрать из заметок учителя (Lesson Log → «Заметки преподавателя», «Что прошли»).
7. Расчёт следующего абонемента — посчитать даты следующего месяца по schedule ученика + цена.
8. **Report Status = `ready to send`** (адресат пока НЕ видит — отчёт спрятан в кабинете).
9. Маша читает draft → правит → переключает на `sent` → отчёт виден родителю/ученику в кабинете.
